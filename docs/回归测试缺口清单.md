## 三、236 项未覆盖的缺口清单

### 覆盖面缺口（本次已补 20 项测试）

- **G1** 未闭合非对称标签 `<tool_call:name>{json}` + 流提前 stop（Symptom B）——现有 662-686 仅覆盖 DSML 外层截断，1079 仅覆盖完整非对称块；a1/a2 固化。
- **G2** 裸标签跨 chunk 拆分的**中间帧文本泄漏**——现有 950-968 只断言最终 fc，不断言中间 chunk 文本；b1/b2 逐帧固化。
- **G3** 非对称块的 schema 校验——现有 1019-1047 只测对称 bare 标签拒绝；c2 固化。
- **G4** 代码围栏内非对称/JSON 体的示例防护——现有 1008-1017 只测 bare 标签围栏；e4 固化。
- **G5** 流式 `finish_reason=function_call` 的 native 调用收口与上下文清理——现有 521-553 只测 `tool_calls`；f5 固化。
- **G6** 死代码事实：`hasUnclosedBareToolBlock`（openai.ts:234）与 `isBlockBoundaryAndNotFenced`（261）已定义但**从未被调用**（grep 佐证，仅定义处 2 次命中）——裸标签流式扣留从未接线，这是 G2 中间帧泄漏的根因；b3 文档化。

### 实现缺口（校准发现，pin 测试已固化现状，修复后翻转断言）

1. **未闭合非对称标签不解析（G1 双路径）**：
   - 非流式：Pass 3b（openai.ts:887-891）要求闭合 `</\1>`；Pass 5 unclosed 兜底（946-960）的 `unclosedRegex` 只认 `<tool_call>`/`<function_call>`（无冒号形式），`<tool_call:list_dir>` 不在兜底 → 整块当正文。
   - 流式：`hasUnclosedToolCallBlock`（213）的 `tcOpens = /<tool_call[>\s]/` 不匹配 `<tool_call:`（冒号后非 `>`/空白）→ 开标签被通用 marker `'<tool_'` 扣住，但后续 JSON 体帧被当普通正文放行泄漏。
2. **裸标签中间帧泄漏（G2）**：`TOOL_CALL_START_MARKERS`（190-201）不含裸标签（`<run_command>` 等）；`<run_command> {"..."` 首帧原文直出。最终闭合后 Pass 4b 仍解析出 fc（不丢调用），但泄漏面在中间帧。
3. **非对称块绕过 schema 校验（G3）**：`validateBareArgs`（830）只挂在 Pass 4b（939）；Pass 3b（889）无校验 → schema 会话下未声明工具 `delete_file` 产出 fc，且 `normalizeToolArgs` 把未声明参数 `Path` 强转 `AbsolutePath`（[Utils] fallback 日志），该调用会被 IDE 以 invalid tool call 终止整轮。
4. **围栏内非对称示例误报（G4）**：`insideCodeFence`（925）只在 Pass 4b 使用；Pass 3/3b/4 不检查围栏 → ` ``` `<tool_call:list_dir>{json}</list_dir>` ``` ` 产出真实 fc。
5. **流式 `function_call` 收口缺失（G5）**：openai.ts:1341 仅在 `finish_reason==='tool_calls'` 收口 native 调用；`function_call`（非流式映射表 1117-1123 明确认识该值）在流式落空 → 返回 null 丢调用，且 `activeStreamContexts` 不清理（仅 stop/length/tool_calls 触发删除，1221-1226/1293/1322/1332/1372）→ 残留上下文污染后续同 id 流。

## 四、真实日志校准方法（rawStreamEnabled + Detected 日志金线）

### 开关（proxy.ts:127-135）

```powershell
# 方式一：flag 文件（与 dashboard/端口状态文件同目录）
New-Item -ItemType File "$env:USERPROFILE\.gemini\antigravity\raw_stream.flag" -Force
# 方式二：环境变量
$env:DSH_RAW_STREAM = '1'
```

开启后每个上游 chunk 打两条日志，按模型名过滤：
- `[Proxy][RAW:<model>] <上游原文 SSE data>` —— 判断模型**真的调用了工具**还是**正文提及**的第一手证据；
- `[Proxy][MAP:<model>] <映射后 Gemini 帧>` —— 验证翻译器输出（fc 出现在哪一帧、finishReason 归一结果）。

### 解析命中金线（openai.ts:1003-1005）

`[Proxy] Detected N text tool call(s): name, ...` —— **文本标签路径**真实调用的唯一判据（native `delta.tool_calls` 路径不经过该日志）。
